# 部署前檢查

## 活動時間基準

管理頁標示台北時間，只代表表單輸入與顯示的約定；尚未確認 AWS 後端的時間設定一致，不能視為已通過部署驗收。

- 核對 EC2 系統時間與時區，以及實際 systemd 服務啟動的 JVM 預設時區；兩者須分別確認，不能只看 SSH 終端機的時間。
- 現有 API 使用不帶時區的 LocalDateTime。核對伺服器的 LocalDateTime.now()、MySQL/JDBC 的日期讀寫與前端 UTC+08:00 約定一致。
- 使用專用活動實測日期往返不偏移，並驗證報名截止前後及活動開始前後的後端判斷。
- 本項待 AWS 部署前實測；本次未更新 AWS，也未調整伺服器時區或登入規則。
